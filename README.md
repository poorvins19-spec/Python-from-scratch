# 🐍 Python Basics and Practice Notebooks

## 📌 About the Project

This repository contains my Python programming practice notebooks created using Jupyter Notebook. The project covers fundamental Python concepts, basic programming logic, conditional statements, loops, lists, and other important topics.

The main objective of this project is to develop programming skills, understand Python syntax, practice problem-solving, and build a strong foundation for learning advanced Python concepts.

## 🎯 Objectives

- Learn the fundamentals of Python programming.
- Understand variables, data types, and operators.
- Practice conditional statements and decision-making.
- Learn looping structures and iteration.
- Understand lists and collection data structures.
- Practice writing and using Python functions.
- Improve logical thinking and problem-solving skills.
- Maintain a collection of Python exercises for future reference.

## 💻 Requirements

To run these notebooks, you need:

- Python 3 installed on your computer.
- Jupyter Notebook or JupyterLab.
- A web browser to access the Jupyter interface.

Most exercises use Python's built-in features and do not require additional third-party libraries.

## 🚀 How to Run the Project

### Option 1: Using Jupyter Notebook

1. Install Python 3 from the official Python website: https://www.python.org/
2. Install Jupyter Notebook using the terminal:

   ```bash
   pip install notebook
   ```

3. Download or clone this repository.
4. Open a terminal inside the project folder.
5. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

6. Open the `notebooks` folder.
7. Select a notebook and run the code cells.

### Option 2: Using Google Colab

1. Open https://colab.research.google.com/
2. Select the GitHub option in the notebook-opening dialog.
3. Enter the URL of this repository.
4. Select the notebook you want to run.
5. Execute the code cells.
